`@qarar/benchmark` is an official, zero-overhead benchmarking package designed to measure engine throughput, query compilation speeds, memory consumption, and batch scalability across datasets of **1,000,000+ rows**.

```bash
pnpm add -D @qarar/benchmark
```

---

## 1. CLI Usage

Run the benchmark CLI directly using pnpm scripts from the monorepo root:

<Tabs>
  <TabItem label="Dataset Stress Test">
    ```bash
    # Test across 100,000 rows (default)
    pnpm bench:dataset

    # Stress-test across 1,000,000 rows
    node packages/benchmark/dist/cli.js --suite dataset --rows 1000000
    ```
  </TabItem>
  <TabItem label="In-Memory Microbenchmarks">
    ```bash
    # Run 100k iteration warm microbenchmarks
    pnpm bench:micro
    ```
  </TabItem>
  <TabItem label="Decision Tables">
    ```bash
    # Run 10-branch and 50-branch scaling benchmarks
    pnpm bench:decision
    ```
  </TabItem>
  <TabItem label="Full Suite">
    ```bash
    # Run all benchmarks and output report
    pnpm bench
    ```
  </TabItem>
</Tabs>

## 2. CLI Options & Flags

| Flag | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| **`--suite`** | `string` | `"all"` | Target suite: `"all"`, `"micro"`, `"dataset"`, `"decision"`. |
| **`--rows`** | `number` | `100000` | Dataset row count for batch stress testing (e.g. `1000000`). |
| **`--domain`** | `string` | `"ecommerce"` | Synthetic data generator domain: `"ecommerce"`, `"fintech"`, `"healthcare"`. |
| **`--format`** | `string` | `"table"` | Output display format: `"table"` (ANSI terminal), `"markdown"`, `"json"`. |
| **`--export`** | `string` | `none` | File path to export report output (e.g. `reports/benchmark.json`). |

### Examples

```bash
# Output Markdown tables for documentation or GitHub PR comments
node packages/benchmark/dist/cli.js --suite all --format markdown

# Export structured JSON metrics for CI performance tracking
node packages/benchmark/dist/cli.js --suite all --format json --export reports/ci-bench.json

# Test FinTech fraud detection rules across 500,000 synthetic records
node packages/benchmark/dist/cli.js --suite dataset --domain fintech --rows 500000
```

## 3. Programmatic API

You can import the benchmark runner and deterministic dataset generators in your own test suites:

```ts
import { 
  BenchmarkRunner, 
  DatasetGenerator, 
  ecommerceComplexRule 
} from "@qarar/benchmark";

// 1. Generate 100,000 deterministic records (Mulberry32 PRNG)
const dataset = DatasetGenerator.generateEcommerce(100_000);

// 2. Measure batch dataset evaluation performance
const metrics = BenchmarkRunner.measureDataset(
  "Complex Promo Evaluation",
  ecommerceComplexRule,
  dataset
);

console.log(`Throughput: ${metrics.throughputOpsPerSec.toLocaleString()} rows/s`);
console.log(`Median Latency: ${(metrics.p50LatencyNs / 1000).toFixed(2)} µs`);
console.log(`Heap Delta: ${metrics.memoryDelta.heapUsedMb.toFixed(2)} MB`);
```
