`@qarar/react-builder` provides a visual rule authoring component (`<RuleBuilder />`) designed for embedding into internal admin portals, SaaS dashboards, and workflow editors.

> [!NOTE]
> This component powers the [Interactive Studio](/playground/) and is maintained as an internal workspace package.

---

## 1. Basic Usage

The `<RuleBuilder />` is a fully controlled React component:

```tsx
import React, { useState } from "react";
import { RuleBuilder, type FieldDefinition } from "@qarar/react-builder";
import type { RuleNode } from "@qarar/spec";

// 1. Define fields available for non-engineers to pick from
const AVAILABLE_FIELDS: FieldDefinition[] = [
  { path: "customer.age", label: "Customer Age", type: "number" },
  { 
    path: "customer.tier", 
    label: "Customer Tier", 
    type: "enum", 
    options: ["bronze", "silver", "gold", "vip"] 
  },
  { path: "cart.total", label: "Cart Subtotal ($)", type: "number" },
  { path: "customer.isVerified", label: "ID Verified", type: "boolean" },
];

export function AdminRuleEditor() {
  const [ruleRoot, setRuleRoot] = useState<RuleNode>({
    type: "and",
    conditions: [
      {
        type: "gte",
        left: { type: "field", path: "customer.age" },
        right: { type: "number", value: 18 },
      },
    ],
  });

  return (
    <div className="p-6 max-w-4xl mx-auto bg-white dark:bg-slate-900 rounded-lg shadow">
      <h2 className="text-xl font-bold mb-4">Edit Promotional Rule</h2>
      
      <RuleBuilder
        fields={AVAILABLE_FIELDS}
        value={ruleRoot}
        onChange={(updatedNode) => {
          setRuleRoot(updatedNode);
          console.log("Updated JSON AST:", updatedNode);
        }}
      />
    </div>
  );
}
```

---

## 2. Component Props

| Prop | Type | Required | Description |
| :--- | :--- | :---: | :--- |
| **`value`** | `Rule \| RuleNode` | Yes | The current rule or root node to render and edit. |
| **`onChange`** | `(node: RuleNode) => void` | Yes | Callback fired whenever a condition or gate is modified. |
| **`fields`** | `FieldDefinition[]` | Yes | List of fields users are allowed to choose from. |

## 4. Visual Decision Table Builder (`<DecisionTableBuilder />`)

Visual authoring for multi-case switch matrices (`DecisionTable`):

```tsx
import { DecisionTableBuilder } from "@qarar/react-builder";
import type { DecisionTable } from "@qarar/spec";

export function AdminMatrixEditor() {
  const [table, setTable] = useState<DecisionTable>(myDecisionTable);

  return (
    <DecisionTableBuilder
      value={table}
      onChange={(updatedTable) => setTable(updatedTable)}
      matchedBranchId="vip-tier" // Optional: highlight active matched branch in real-time
    />
  );
}
```

### Component Props

| Prop | Type | Description |
| :--- | :--- | :--- |
| **`value`** | `DecisionTable<T>` | The decision table AST to render and edit. |
| **`onChange`** | `(table: DecisionTable<T>) => void` | Fired when branches, conditions, or outputs change. |
| **`matchedBranchId`** | `string \| null` | Optional branch ID to highlight with green `MATCHED` badge. |
| **`theme`** | `QararTheme` | Optional CSS variable tokens for styling. |
