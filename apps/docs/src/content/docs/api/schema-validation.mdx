When building mission-critical services, evaluating rules against untrusted or malformed input payloads can lead to silent false negatives.

`createQarar` binds Qarar to any domain schema validator (implementing the Standard Schema `.safeParse()` interface). It automatically validates incoming data payloads before executing rules, ensuring that missing fields or type mismatches are caught immediately — with zero external dependencies required by Qarar.

---

## 1. `createQarar(schema)`

```ts
import { createQarar } from "@qarar/sdk";

// Define a domain schema validator (any object with a .safeParse method)
export const CustomerContextSchema = {
  safeParse(data: unknown) {
    if (
      data &&
      typeof data === "object" &&
      "customer" in data &&
      typeof (data as any).customer?.age === "number"
    ) {
      return { success: true as const, data };
    }
    return {
      success: false as const,
      error: {
        issues: [{ path: ["customer", "age"], message: "Expected valid customer age" }],
      },
    };
  },
};

// Create schema-bound Qarar instance
export const q = createQarar(CustomerContextSchema);
```

---

## 2. Schema-Enforced Evaluation

Use `q.check(rule, payload)` to validate input data and evaluate in a single step:

```ts
// 1. Build rule
const promoRule = q.rule("VIP Checkout Promo")
  .where("customer.age").gte(18)
  .and("customer.tier").in(["gold", "vip"])
  .and("cart.total").gte(100)
  .build();

// Case A: Valid Payload ➔ Evaluates rule
const validCheck = q.check(promoRule, {
  customer: { id: "cust_123", age: 24, tier: "vip" },
  cart: { total: 150, itemCount: 2 },
});

console.log(validCheck.ok);      // true (Schema valid)
console.log(validCheck.result);  // true (Rule passed)

// Case B: Malformed Payload (age is wrong type) ➔ Caught by Schema
const invalidCheck = q.check(promoRule, {
  customer: { id: "cust_123", age: "invalid-age", tier: "vip" },
  cart: { total: 150, itemCount: 2 },
});

console.log(invalidCheck.ok);      // false (Schema invalid!)
console.log(invalidCheck.reasons); // ["Data error at customer.age: Expected valid customer age"]
```
