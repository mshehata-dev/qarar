## SDK Installation

Install the main SDK package using your package manager of choice:

```bash
# npm
npm install @qarar/sdk

# pnpm
pnpm add @qarar/sdk

# yarn
yarn add @qarar/sdk
```

## Visual Builder (Optional for React Apps)

If you are building a React web application or admin portal and want to embed the visual rule authoring UI, install `@qarar/react-builder`:

```bash
# npm
npm install @qarar/react-builder

# pnpm
pnpm add @qarar/react-builder
```

## Peer Dependencies

`@qarar/sdk` requires **Zod** (`^3.24.0`) for schema validation. It is installed automatically as a dependency.
