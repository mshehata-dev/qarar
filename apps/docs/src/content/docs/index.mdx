When business requirements evolve, engineers shouldn't need to write code, open PRs, and wait for CI/CD deployments. **Qarar turns business logic into portable JSON ASTs.** Store rules in PostgreSQL, MongoDB, or Redis, evaluate them in Node.js at **3.5M+ rows/second**, or push them directly down into database queries.

## 30-Second Example

Define a rule in JSON, evaluate any JavaScript data object, and get instant true/false results with human-readable explanations:

```ts
import { checkRule, rule } from "@qarar/sdk";

// 1. Define rule (or fetch existing JSON AST from your database)
const loyaltyGate = rule("VIP Checkout Discount")
  .where("user.tier").in(["vip", "platinum"])
  .and("cart.total").gte(100)
  .build();

// 2. Evaluate incoming request payload
const { result, reasons } = checkRule(loyaltyGate, {
  user: { tier: "bronze" },
  cart: { total: 150 }
});

console.log(result);  
// ➔ false

console.log(reasons); 
// ➔ ["user.tier: \"bronze\" is not in [vip, platinum]"]
```
